Notes

Contactable % is measured against total unique customers called. Contactable Active % (Retention) is measured against contactable customers. Customers with a Churn Request / LBO Shifted to Other ISP reason count as Contacted (the agent did reach them and confirm the outcome) but are excluded from the Active/Retained count even if the system still shows them as Active — they have already left the network and cannot be retained.

De-duplication rule, applied consistently across all three pages:

  • If the same User Id appears in more than one calling sheet in the same period, the sheet priority Suspended > Upcoming > Inactive decides which row counts, regardless of call date.
  • If the same User Id appears more than once within the same sheet in the same period (multiple call attempts that month), the row that appears later/lower in that month's data counts.

The Churn Request / LBO Shifted to Other ISP count follows this same de-duplication rule, so it stays consistent with the Contactability and Retention figures.
